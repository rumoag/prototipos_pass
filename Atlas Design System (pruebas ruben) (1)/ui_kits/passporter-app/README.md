# Passporter App — UI Kit

A high-fidelity visual recreation of Passporter's web app surfaces using the Atlas design system. Open `index.html` for an interactive click-through demo.

## Components

- `Sidebar.jsx` — left navigation with trip switcher and section list
- `TopBar.jsx` — search + user menu
- `TripCard.jsx` — trip preview card with hero image, dates, places
- `IdeaCard.jsx` — saveable place/idea card with bookmark + category
- `Modal.jsx` — Atlas modal (hero image, title, description, CTA)
- `Button.jsx` — Filled / Outlined / Ghost / Brand variants
- `BottomTabs.jsx` — mobile tab navigation
- `Toast.jsx` — feedback toasts

All components share state in `index.html` for the click-thru.
